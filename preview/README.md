# Connectly interactive preview

This ZIP packages the Phase 1 frontend from application commit `ad3e7a9` as a self-contained HTML preview.

1. Download `Connectly-interactive-preview.zip` from this folder (on GitHub, choose **Download raw file**).
2. Extract the ZIP.
3. Open `Connectly-preview.html` in Chrome or Edge.

No localhost server, terminal, dependency installation, or Internet connection is required to use the extracted preview. It contains the styles, JavaScript, images, and asset notices. Navigation, likes, bookmarks, comments, follows, and mock posting are interactive.

All people and activity are fictional. Posts, comments, and selected photos reset on reload; likes, bookmarks, and follows use browser storage where available. This preview does not connect to a backend or database.

The original application remains on branch `work`. This distribution branch adds only the packaged preview and these instructions.
